## What is Facil Framework?

A generic deployable framework for digital services platforms (gov / enterprise / SaaS / banking / telco / HR / real estate / e-commerce), customizable without code via a Customization Studio, deployable on any cloud or on-prem.

Cloned in snapshot from **TaxasGE** (Equatorial Guinea gov digital services) on 2026-05-10. Open Core AGPL-3.0.
